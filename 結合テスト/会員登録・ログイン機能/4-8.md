- **前提条件**:


  - `customers`テーブルに email="notfound@example.com" の顧客が存在しない。


- **手順**:


  - `HTTP POST`リクエスト `/api/customers/login` に送信。


- **入力データ**:


  - json
{ "email": "notfound@example.com", "password": "password123" }
- **期待結果**:


  - `HTTP`ステータスコードが `401 Unauthorized` であること。
