# 機能：注文機能

## テスト対象API

- `POST /api/orders`

## テストデータ準備方針：

- テストの独立性を保つため、各テストケース実行前にデータベースをクリーンな状態にし、テストケースごとに必要な商品データを投入することを想定します。
- 以下では、テストデータとして投入される商品情報を `Product(ID, Name, Price, Desc, Stock, ImageUrl, IsRecommended)` の形式で記述します。

## テストシナリオ

### No. 3-18

- テストケース名: 注文（異常系 - 顧客情報の形式が不正、例：メール形式不正）
- 前提条件:
    - DBにテスト商品として以下の商品が登録されていること:
        - `Product(1, "商品A", 500, "テスト用の商品Aです", 10, "/images/productA.png", false)`
    - セッションに以下のカート情報が存在すること:
        - `Cart(items={"1": CartItem(productId=1, quantity=1, ...)})`

- 手順:
    1. HTTP POSTリクエストを `/api/orders` エンドポイントに送信する。
        - **HTTPリクエスト**: `POST /api/orders`
        - **リクエストボディ**:
            ```json
            {
              "customerInfo": {
                "name": "顧客 一郎",
                "email": "invalid-email", 
                "address": "東京都千代田区テスト1-1",
                "phoneNumber": "03-1234-5678"
              },
              "paymentMethod": "銀行振込"
            }
            ```
        - **セッション**: 上記前提条件のカート情報
    2. -> OrderController
    3. OrderControllerの`placeOrder`メソッドの引数`@Valid @RequestBody OrderRequest orderRequest`に対するバリデーションが実行される。
    4. `OrderRequest`内の`customerInfo.email`が不正な形式であるため、`MethodArgumentNotValidException`が発生する。
    5. OrderControllerの`@ExceptionHandler(MethodArgumentNotValidException.class)`で定義された`handleValidationExceptions`メソッドが呼び出され、エラーレスポンスを生成する。
    6. HTTPレスポンスを受信する。

- 入力データ:
    ```json
    {
      "customerInfo": {
        "name": "顧客 一郎",
        "email": "invalid-email", 
        "address": "東京都千代田区テスト1-1",
        "phoneNumber": "03-1234-5678"
      },
      "paymentMethod": "銀行振込"
    }
    ```

- 期待結果:
    1. HTTPステータスコードが **`400 Bad Request`** であること。
    2. レスポンスボディがJSON形式であり、`customerInfo.email` に関するバリデーションエラーメッセージ（例: `"有効なメールアドレスを入力してください"` など、`OrderRequest` DTOのバリデーションメッセージに依存）を含む `OrderResponse` であること。複数のエラーがある場合は `;` で連結されること。
    3. `OrderController` の `placeOrder` メソッドに到達するが、`@Valid` アノテーションによるバリデーションで `MethodArgumentNotValidException` が発生し、`handleValidationExceptions` メソッドで処理されること。`OrderService` は呼び出されないこと。
    4. DB状態変化: なし。
    5. セッション状態変化: なし。
